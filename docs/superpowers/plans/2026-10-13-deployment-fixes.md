# 每日模拟策略部署修复计划

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 修复检查中确认的运行和记账缺陷，交付可测试的 GitHub Actions 项目和上传指引。

**Architecture:** 保留因子、κ=100 QP 和权重型模拟组合，补充按交易日推进的账本。日常只获取已有持仓的带日期日线；调仓获取当前股票池历史、市值和行业。状态仍通过 Git 提交持久化，单个原子账本作为恢复依据。

**Tech Stack:** Python 3.12、pandas、AKShare、CVXPY、GitHub Actions、unittest。

**Spec:** 用户已授权修复《部署检查/2026-10-13-icir-tc/检查报告.md》所列缺陷；不采用之前未确认的外部对象存储设计，不推送、不自动启用日程。

## Global Constraints

- 只做模拟，不连接券商；不改变 κ=100、因子方向和现有约束数值。
- 不倒填调仓。缺日按原持仓补估值，漏掉月初调仓延迟到恢复日；信号使用前一交易日，执行日收盘模拟。
- 第一次运行可在最近完整交易日初始化，报告清楚标注历史 IC 尚未预热的等权回退。
- 数据缺失、过期、无法验证的停牌不得当成零收益；退出成分仍在账本中直到模拟卖出。
- 报告包含真实扣费净值、官方指数基准、策略版本和异常说明；不沿用未经复现的历史绩效宣传。

## Review Focus

- 同日重试、休市和补偿定时不得重复扣费或重复记收益。
- 失败或缺数据时不能推进账本；求解失败保留旧组合。
- 缺日且跨月不能用当前快照倒推过去的调仓。
- 股票退出指数后，旧持仓收益与卖出费用仍完整计算。
- Git 提交失败要保留可下载产物，不能静默丢失一次运行状态。

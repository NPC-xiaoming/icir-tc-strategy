# ICIR-TC 每日模拟组合

使用 AKShare、Python 3.12 和 GitHub Actions，收盘后生成沪深300指数增强模拟组合日报；月度生成目标权重和调仓 CSV，并更新模拟持仓。策略版本 `1.0.1`。上传操作见 [UPLOAD_GUIDE.md](UPLOAD_GUIDE.md)。

## 运行规则

- 自动任务预定北京时间工作日 **17:10** 和 **18:30**，A 股休市日跳过。第二次用于补跑；已成功保存的同一交易日直接跳过。GitHub 定时任务可能延迟或漏触发，不保证准点。
- 自动运行默认关闭，手动验证成功后设置仓库变量 `ENABLE_DAILY=true`。
- 首次在交易日 16:00 后运行时尝试建仓，不必等下个月。首次净值从 1 开始，扣除买入费用；不追溯建仓前收益。
- 此后月内首次成功运行时尝试调仓，正常为首个交易日。漏跑按原持仓逐日补估值，恢复日才调仓，不补造过去的交易。
- 信号和协方差使用前一交易日数据；市值约束使用执行日收盘快照；按执行日收盘进行权重型模拟，新持仓从下一交易日取得收益。
- 收益沿用原策略带日期的后复权日线涨跌幅代理；权重按该代理自然漂移。费用按买卖权重估计并扣净值；退出指数的旧持仓仍计收益，卖出计入换手和费用。
- 基准为官方沪深300**价格指数**，不是当前成分合成的指数。组合的复权收益与价格指数分红口径不同。
- 缺行情、缺市值、行业映射不完整或数据日期不符时失败并保留原账本。停牌缺行也会暂停，不能自动把缺行认作零收益。
- 优化不可行时保留漂移后的原组合，日报说明原因，下一个交易日再尝试；首次失败保持现金。不得把优化失败误认为成功调仓。

## 策略边界

保留原有三个因子（120/20 动量、60 日波动、20 日换手）、κ=100、行业/市值/个股偏离/换手预算。市值约束现在实际传入优化器，退出成分的卖出计入双边换手。首次从现金建仓豁免 25% 双边换手限制。

**这是一条新模拟账本，不是研究回测的接续。** 未导入历史 IC，按原有算法在 IC 样本不足时使用等权因子回退。当前 24 期窗口、2 期滞后，通常至少积累 14 条月度 IC 后才可能脱离样本不足状态；单因子缺值或 IC-IR 非正仍可能回退。真实历史表现须另做历史数据与研究版本核对。

**后复权收益代理不等于真实资金盈亏。** 例如 000001 在 2026-10-13 的未复权日涨跌幅约 −1.36%，后复权序列涨跌幅约 −1.04%；即使当天没有公司行动也可能不同。这次部署修复保留原策略研究口径，未另建股份、现金和分红流水账。不能用这份净值冒充真实可交易组合收益。快照日期交叉核对另外抓取当日未复权日线，不与后复权涨跌幅混比。

这是权重模拟，不含整手、现金尾差、停牌/涨跌停成交约束、真实冲击成本或券商下单；执行日收盘信息并不代表可获得同价成交。目前没有导入外部调仓文件或邮件推送功能。

## 云端持久存储

每次 Actions 获得一台临时机器，先下载代码和上一日 `state/`，计算完将新状态和报告提交回**私有 GitHub 仓库**。机器销毁后，仓库文件仍在，下次接着运行。

| 路径 | 用途 |
|---|---|
| `state/book.json` | 唯一权威账本：持仓、净值、IC 和处理日期；原子替换 |
| `state/*.parquet`、`state/meta.json` | 便于分析的导出副本，以 book.json 为准 |
| `state/industry_sw_l1.parquet` | 行业缓存，云任务每月刷新 |
| `reports/daily/YYYY-MM-DD.md` | 当日净值、收益、超额、持仓和近20日记录 |
| `reports/rebalance/YYYY-MM-DD.md` | 因子权重、约束、成本和调仓诊断 |
| `reports/rebalance/YYYY-MM-DD_trades.csv` | 成功调仓的完整前后权重清单 |

仓库是小规模模拟组合的持久存储。Actions Artifact 是额外排错/恢复包，配置保留 30 天，**不能替代账本**。推送失败时任务报错，不强推或自动合并冲突账本。长年高频保存大表会增加仓库体积，届时再迁移对象存储；无需现在部署数据库。

## 本地验证

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
```

测试使用临时目录和模拟行情，不联网拉取全市场、不写真实账本。直接运行 `python run.py` 会写本地模拟账本；云端启用后不要再以这份本地目录并行运行另一条账本。

直接依赖版本已固定，传递依赖由 pip 解析。CI 在 Ubuntu/Python 3.12 执行离线测试。AKShare 免费接口可能限流、调整字段或拒绝云端 IP，因此首次云端全量运行需要验收；不能仅凭本地测试声称可长期无人值守。
